Accessibility notes

WCAG 2.2 AA. Applies to every screen on this canvas. Contrast values are the design system's.

Rules for every screen

TopicRule
ContrastBody ink on page 14.0:1; captions slate 5.0:1; status words 5.6 to 12.9:1 on their tints; control borders control-border 3.6:1; focus ring navy 14.6:1. Gold never carries text on light grounds.
Not colour aloneEvery status has a word. Step states also differ by marker: tick (done), number with halo (yours), clock (waiting), "!" (problem). Map pins are named in the chip.
Targets48 x 48 dp minimum, 56 dp for driver primaries. Quiet text buttons keep 48 dp height. At least 8 dp between adjacent targets.
Text sizeWorks at 200% system font: cards grow, nothing truncates except the header (full name is in its accessible label). Fact rows wrap to stacked label over value. The sticky action bar stays; content scrolls above it.
WidthAll screens built at 360 dp; no horizontal scroll. Web tables scroll inside their own box.
Icon buttonsNone in the app: every action has a word. Decorative icons are aria-hidden. Copy buttons are labelled with what they copy: "Copy truck number KA01AB1234".
MotionSpinners respect reduce-motion (show the word only). Sheets fade, no slide, when reduce-motion is on.
Dark modeOff. The app does not follow the phone's dark setting.

Role checks to test

  • Signed in as a driver, search every screen's accessibility tree for "₹", "paid", "commission", "receive", "payout", "net". None may appear.
  • Signed in as a dispatcher, the payment block and bank details never render, and the status reads "Delivery confirmed".
  • Signed out, no tabs render; only the start screen and sign-in.
